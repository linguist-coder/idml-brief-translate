IDML Brief Translate @VERSION@ (Windows 64-bit)

Start: double-click IDMLBriefTranslate.exe. A console window opens and your
browser shows the app. Close the console window to quit.

Windows may warn that the app is from an unknown publisher (it is not signed).
Choose "More info" > "Run anyway" only if you downloaded this zip from
https://github.com/linguist-coder/idml-brief-translate/releases

sample\tx40_ja_base.idml is a test document (English, 4 pages).
API keys (Anthropic for translation, OpenAI for review) are kept in memory
while the app runs and are never saved. The text of your document, the brief
and the glossary are sent to Anthropic and OpenAI when you run translation
and review.

Output: Documents\IDMLBriefTranslate (working IDML + HTML report).
Working files: %LOCALAPPDATA%\IDMLBriefTranslate
